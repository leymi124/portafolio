# Portafolio Profesional — Leymi

Este es un proyecto de portafolio web personal desarrollado para la materia de Desarrollo Web / Computación. El sitio incluye información sobre mi formación académica en el **CECyT 3 "Estanislao Ramírez Ruíz"**, mis proyectos técnicos y mis habilidades en programación, animación y sistemas.

##  Características del Proyecto
- **Semántica HTML5**: Estructura limpia y accesible bajo estándares WCAG.
- **Diseño Responsivo**: Maquetado adaptable a dispositivos móviles y escritorio usando CSS3 (Flexbox/Grid).
- **Interactividad Vanilla JS**: Menú hamburguesa responsivo, desplazamiento suave (Smooth Scroll) y formulario interactivo.
- **Modo Oscuro**: Alternancia de tema claro/oscuro guardando la preferencia del usuario con `localStorage`.
- **Rendimiento Perfecto**: Calificación 100/100 en auditorías de Lighthouse (Performance, Accessibility, Best Practices y SEO).

##  Tecnologías Utilizadas
- HTML5
- CSS3 (Variables / Custom Properties)
- JavaScript (ES6+)
- XAMPP / Apache Localhost
